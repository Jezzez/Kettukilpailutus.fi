# Kettu-maskotin asennot

- `kettu-kortti.webp/png` — lepoasento, kortti kädessä (hero)
- `kettu-osoittaa.webp/png` — osoittaa sormella (neuvot, vinkit)
- `kettu-peukku.webp/png` — peukku ylös (onnistumiset, hyvä osuma)

Asentoja vaihdetaan komponentissa `components/mascot/Kettu.tsx`.
Uuden asennon lisääminen: lisää tiedosto tähän kansioon ja rivi
Kettu.tsx:n `ASSETS`-objektiin.

Kaikki kuvat: läpinäkyvä tausta, WebP ensisijainen (kevyempi), PNG varmuuskopiona.
